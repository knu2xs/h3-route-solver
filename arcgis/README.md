# h3-route-solver Python Toolbox (`h3_route_solver.pyt`)

This is the documentation to be included if planning on packaging the `h3_route_solver.pyt`
toolbox using the `make pyt_pkg` command invoking the `./scripts/make_pyt_archive.pyt`. This script
packages the `h3_route_solver.pyt`, supporting Python package 
`./src/h3_route_solver` and any dependencies listed in `pyproject.toml`. This enables you to
distribute the Python toolbox for non-technical users with any custom libraries you are utilizing.
